# SPSS at Tufts

IBM SPSS Statistics is a widely used software package for statistical analysis, data management, and visualization. It is commonly used in social sciences, public health, education, and survey research. SPSS is available to all Tufts faculty, staff, and students at no cost through several access methods.

For full details on Tufts SPSS access and licensing, see: [access.tufts.edu/spss](https://access.tufts.edu/spss)

---

## Access Methods

### Method 1: TTS Virtual Lab (Recommended for Remote Access)

The TTS Virtual Lab provides SPSS through a browser-based virtual desktop — no local installation required. This is the recommended option for remote work.

**Step 1 — Connect to the Tufts VPN (off-campus users):**

If you are off campus, connect to the [Tufts VPN](https://access.tufts.edu/vpn) before proceeding.

**Step 2 — Access the Virtual Lab:**

Navigate to the Tufts Virtual Desktop at [https://vdi.tufts.edu](https://vdi.tufts.edu) and log in with your Tufts credentials (UTLN and password).

**Step 3 — Launch SPSS:**

From the virtual desktop, open **IBM SPSS Statistics** from the Start menu or desktop shortcut.

**Saving your work:**

Files saved within a Virtual Lab session persist only on the virtual desktop's local storage unless saved to a mapped network drive. To avoid losing work:

- Save output and data files to your Tufts network storage (mapped drive) if available, or
- Download files to your local machine before ending the session

Virtual Lab sessions may have time limits. Save frequently and do not leave idle sessions running.

---

### Method 2: Tufts Computer Labs

SPSS is installed in most Tufts computer labs on campus. This is a good option for on-campus users who prefer a dedicated workstation or need a faster connection for large datasets.

Contact [Tufts Technology Services](https://it.tufts.edu) or visit [it.tufts.edu](https://it.tufts.edu) for a current list of labs with SPSS installed.

---

### Method 3: Local Installation via On The Hub

You can install SPSS on your personal computer through Tufts' software portal.

**Step 1 — Access On The Hub:**

Go to [tufts.onthehub.com](https://tufts.onthehub.com) and log in with your Tufts credentials.

**Step 2 — Find SPSS:**

Navigate to **Institutional Software** and search for SPSS.

**Step 3 — Download and install:**

Follow the on-screen instructions to download and activate the software. If you encounter issues, contact TTS at [it@tufts.edu](mailto:it@tufts.edu) or call 617-627-3376.

## Available Modules

The Tufts SPSS license includes the following 15 modules:

| Module                 | Description                                                        |
| ---------------------- | ------------------------------------------------------------------ |
| SPSS Base              | Core data management, descriptive statistics, and basic procedures |
| Regression             | Linear, logistic, ordinal, and nonlinear regression                |
| Advanced Statistics    | GLM, mixed models, survival analysis, and multivariate procedures  |
| Missing Values         | Missing data diagnostics and imputation                            |
| Decision Trees         | Classification trees (CHAID, CART, C5.0, Quest)                    |
| Complex Samples        | Survey-weighted analysis for complex sample designs                |
| Neural Networks        | Multilayer perceptron and radial basis function networks           |
| Categories             | Optimal scaling, correspondence analysis, and CATPCA               |
| Visualization Designer | Advanced chart and graph creation                                  |
| Data Preparation       | Automated data validation and preparation                          |
| Forecasting            | Time series modeling and forecasting                               |
| Direct Marketing       | RFM analysis and propensity scoring                                |
| Conjoint               | Conjoint analysis for preference research                          |
| Bootstrapping          | Bootstrap estimation for confidence intervals                      |
| Exact Tests            | Exact significance tests for small or sparse samples               |

```{note}
Not all modules may be available in every access method. If a specific module is unavailable in the Virtual Lab, try a local installation via On The Hub or contact TTS for assistance.
```
