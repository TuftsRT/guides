# MATLAB on the Tufts Virtual Desktop (VDI)

The Tufts Virtual Desktop Infrastructure (VDI) provides a full Windows desktop environment in your browser, with MATLAB pre-installed and licensed for Tufts users. This is the recommended option for interactive MATLAB work — building scripts, visualizing data, and using the MATLAB IDE — without installing anything locally.

**When to use the VDI:**

- Interactive development and debugging
- Using the MATLAB IDE, Live Editor, or Simulink
- Short-to-medium analyses that do not require dedicated HPC resources
- Users who prefer a familiar desktop MATLAB experience

**When to use the HPC cluster instead:**

- Long-running jobs (hours to days)
- Jobs requiring large memory or many CPU cores
- Batch processing of many scripts or datasets

---

## Prerequisites

### 1. Tufts MATLAB license

All Tufts faculty, staff, and students have access to MATLAB through the Tufts campus license. Confirm your eligibility and access the license portal at:

[https://access.tufts.edu/matlab](https://access.tufts.edu/matlab)

### 2. Tufts credentials

Log in with your Tufts username (UTLN) and password. No additional software installation is required.

### 3. VPN (off-campus users)

If you are connecting from off campus, connect to the [Tufts VPN](https://access.tufts.edu/vpn) before accessing the VDI.

---

## Accessing the VDI

1. Navigate to the Tufts Virtual Desktop at [https://vdi.tufts.edu](https://vdi.tufts.edu).

1. Log in with your Tufts credentials.

1. Launch the **Tufts Virtual Desktop** session. The desktop will open in your browser.

1. From the desktop, open **MATLAB** from the Start menu or desktop shortcut.

---

## Working in MATLAB on the VDI

Once MATLAB launches, you have access to the full MATLAB IDE:

- **Command Window** — run commands interactively
- **Editor** — write and save `.m` scripts and functions
- **Live Editor** — create interactive notebooks combining code, output, and text
- **File Browser** — navigate your files; use the VDI's file system or map a network drive to access your Tufts storage

### Saving your work

Files saved within a VDI session persist only on the virtual desktop's local storage unless you save them to a mapped network drive or transfer them out. To avoid losing work:

- Save scripts to your Tufts network storage (mapped drive) if available, or
- Download files to your local machine before ending the session

### Session limits

VDI sessions may have time limits or be subject to resource constraints. Save your work frequently and do not leave idle sessions running.
