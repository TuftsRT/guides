# R for Research and Data Science

Welcome to the Tufts RT R documentation!

This guide is for researchers, students, and staff who want to use R for statistics, data analysis, data visualization, and data science. If you are new to R, start with the introduction page to learn what R is and whether it is right for you. If you already know R, jump to the setup guide or tutorials most relevant to your needs.
