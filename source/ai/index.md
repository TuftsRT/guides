# AI and Data Science

This section covers data science programming languages, statistical software, and AI tools available to Tufts researchers. Whether you are analyzing data in Python or R, running statistical models in Stata, SAS, or MATLAB, or using Tufts HPC-hosted AI applications for transcription, document search, or large language models, you will find setup guides, tutorials, and HPC workflow documentation here.
