# Getting Started with AI

This section covers the commercial generative artificial intelligence (AI) tools available to Tufts researchers: the desktop chat applications and the agentic coding assistants that run on your own machine. It explains how to install them, which research data is appropriate for each, and how to configure them so that data stays protected.

These guides cover software that runs locally. For AI applications hosted on the Tufts High Performance Computing (HPC) cluster, including open-source chatbots, optical character recognition, and speech recognition, see [Artificial Intelligence Tools](../ai-tools/index.md).

```{note}
These guides provide general guidance for researchers using generative AI tools in research. They are intended to support informed decision-making and should not be interpreted as University policy or as a substitute for applicable regulatory, contractual, sponsor, Institutional Review Board (IRB), or other research requirements. Researchers remain responsible for ensuring that their use of AI complies with all applicable obligations and should consult Tufts Technology Services (TTS) when guidance for a specific use case is needed.
```

```{attention}
Confidential or regulated data (Institutional Data Level 3) may not be used with any of the tools described in this section. Check the [Data Finder](https://access.tufts.edu/data-finder) before you start, and email <tts-research@tufts.edu> with any questions about using these products with research data.
```
